# notion-widgets

Resizable currency converter widgets to add to your Notion Page. Currency supported : AUD -> EUR, HKD, HUF
Use https://karellu.github.io/notion-widgets/{currency}

Example : AUD -> EUR
https://karellu.github.io/notion-widgets/EUR
